# Лабораторная работа №5. DOM и взаимодействие с элементами страницы

## Цель работы

Научиться манипулировать DOM-деревом, находить элементы, изменять содержимое и стили, а также сохранять состояние страницы между перезагрузками через `localStorage`.

## Описание проекта

Страница «О себе» с интерактивным списком карточек проектов. Карточки можно добавлять и удалять, список можно сворачивать, тему страницы можно переключать. Состояние сохраняется в `localStorage`.

## Структура страницы

Шапка с навигацией и кнопкой темы, аватар и боковая панель, секции «Навыки», «Проекты» (динамический список карточек), «Скриншоты проектов» (Grid-галерея с просмотром по клику), «Обратная связь», подвал.

## Реализованные функции

- Поиск элементов: `document.getElementById` (кнопки), `document.querySelector` (контейнер проектов), `document.querySelectorAll` (карточки)
- Кнопка «Добавить проект»: через `document.createElement` создаётся `<article>` с `<h3>`, `<p>` и кнопкой «Подробнее», данные вводятся через `prompt`, карточка добавляется через `appendChild`
- Кнопка «Удалить последний»: проверка наличия карточек через `querySelectorAll`, удаление через `remove()`; если карточек нет, в консоль выводится «Нет проектов для удаления» и показывается `alert` «Список пуст»
- Переключение темы: кнопка меняет класс `theme-light` / `theme-dark` у `<body>`, цвета задаются CSS-переменными
- Кнопка «Свернуть проекты»: добавляет и убирает класс `hidden` у контейнера списка
- Кнопка «Подробнее» у каждой карточки: раскрывает и сворачивает описание (меняются класс, текст и атрибут `aria-expanded`)
- Обработка ошибок: перед работой проверяется существование контейнера и кнопок, при отсутствии элемента ошибка пишется в консоль и скрипт не выполняется
- `localStorage`: сохраняются список проектов (при добавлении и удалении) и выбранная тема; при загрузке страницы они восстанавливаются
